# Cube-timer
Speedcubing timer with 3x3 scrambles, inspection, and Ao5/Ao12 stats.
Longer (store listing or README):
Speedcube Timer is a simple, fast timer for solving the Rubik's cube. Hold space or the screen, release when it turns green, and tap to stop. Each solve comes with a fresh random 3x3 scramble and a 3D cube you can drag to check the scrambled position. It also has an optional 15-second inspection, +2 and DNF penalties, and live best, mean, Ao5 and Ao12 stats. It works offline and keeps your session on your device.
